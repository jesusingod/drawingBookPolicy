Google Drive Cloudflare R2

📁 Google Drive 설정 방법

1

폴더 공유 설정

도안용 폴더를 만들고 [공유 > 링크가 있는 모든 사용자]로 권한을 변경합니다. 폴더 주소를 복사하세요.

2

API 키 발급

Google Cloud Console에서 Google Drive API를 활성화하고 API 키를 생성합니다.

🟠 Cloudflare R2 설정 방법

R2는 비용이 저렴하고 속도가 빠릅니다. (전문가용 추천)

1

버킷(Bucket) 생성 및 파일 업로드

1. Cloudflare 대시보드에서 R2 > Create bucket을 눌러 버킷을 만듭니다.
2. 버킷 안에 색칠 도안 이미지를 업로드합니다.

2

API 토큰(Access Key) 생성

1. R2 > Manage R2 API Tokens로 이동합니다.
2. Create API token을 누르고 Object Read & Write 권한을 선택합니다.
3. 생성된 Access Key ID와 Secret Access Key를 복사해 두세요.

3

공유 주소(Public URL) 설정

버킷 설정의 Public Access 탭에서 커스텀 도메인이나 R2.dev 주소를 활성화하세요. 이 주소를 통해 앱에서 이미지를 볼 수 있습니다.

💡 Endpoint는 Cloudflare 계정 ID가 포함된 주소 형식입니다.
