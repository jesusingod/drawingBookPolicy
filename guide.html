우리 아이에게 무한한 그림 세상을 선물하세요!

☁️ 구글 드라이브 연결이 무엇인가요?

부모님이 구글 드라이브 폴더에 그림 파일을 넣어두면, 아이가 앱에서 그 그림들을 바로 불러와 색칠할 수 있는 기능입니다. 매번 앱을 업데이트하지 않아도 새로운 도안을 언제든 추가해 줄 수 있어요!

🚀 설정 방법 (3단계)

1

드라이브 폴더 준비 및 공유

1. 구글 드라이브에서 색칠 도안용 새 폴더를 만듭니다.
2. 폴더를 우클릭하고 [공유]를 누릅니다.
3. 일반 액세스를 [링크가 있는 모든 사용자]로 변경합니다.
4. 해당 폴더의 주소(URL)를 복사해 두세요.

💡 폴더가 '공개' 상태여야 앱에서 도안을 읽어올 수 있습니다.
2

구글 클라우드 API 키 발급

이 단계는 PC에서 하시는 것을 추천합니다.

1. 구글 클라우드 콘솔에 접속합니다.
2. 새 프로젝트를 생성합니다.
3. [API 및 서비스 > 라이브러리]에서 "Google Drive API"를 찾아 [사용]을 누릅니다.
4. [사용자 인증 정보 > 인증 정보 만들기]에서 [API 키]를 선택하여 생성합니다.
5. 생성된 API 키를 복사하세요.

3

앱에 입력하기

1. drawingBook 앱의 [설정 > 클라우드 연결]로 들어갑니다.
2. 복사한 API 키와 폴더 주소를 각각 붙여넣습니다.
3. [연결 테스트]를 눌러 성공 메시지가 나오면 저장하세요!

❓ 자주 묻는 질문

Q. 어떤 이미지 파일을 넣어야 하나요?
A. 흰색 배경에 검은색 선으로 된 JPG 또는 PNG 파일을 권장합니다.

Q. 연결이 안 된다고 나와요.
A. 드라이브 폴더 공유 설정이 "링크가 있는 모든 사용자"로 되어 있는지, 그리고 API 키가 올바른지 다시 확인해 주세요.
