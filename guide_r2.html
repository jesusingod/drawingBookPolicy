🟠 Cloudflare R2 가이드

고성능 스토리지로 더 빠르게 도안 로딩하기

🚀 설정 방법 (3단계)

1

버킷 생성 및 파일 업로드

R2 대시보드에서 버킷을 생성하고 이미지를 업로드합니다.

2

API 토큰 발급

Manage R2 API Tokens에서 Access Key ID와 Secret Access Key를 발급받습니다.

3

Public Access 설정

버킷의 Public Access 탭에서 커스텀 도메인이나 R2.dev 주소를 활성화하여 '공유 주소'를 준비합니다.
